# ADURE Website Wireframe

Desktop HTML wireframe for the ADURE public website, structured around three connected capability pillars:

- Sales, with dedicated Buy and Sell journeys
- Leasing
- Property Management

The wireframe also distinguishes portfolio properties from flagship and upcoming development projects.

## View locally

Open `dist/index.html` in a browser. The wireframe is a self-contained HTML prototype and does not require a build step.
